# Streaming Quickstart (SSE)

Stream live Wikimedia edits using Server-Sent Events.

## Quick Start

Install streaming support:

```bash
pip install "lakelogic[sse]"
```

Open streaming_quickstart.ipynb for a guided walkthrough.
