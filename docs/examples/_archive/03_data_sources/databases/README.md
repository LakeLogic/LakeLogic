# Database Sources

Database connector examples organized by engine.

## Available Examples

- azure_sql/ - Azure SQL Database (includes CDC sample)
- sqlserver/ - SQL Server
- oracle/ - Oracle Database
- postgres/ - Postgres
- sqlite/ - SQLite

## Quick Start

Open the notebooks:

- azure_sql/azure_sql_demo.ipynb
- azure_sql/cdc/azuresql_cdc_demo.ipynb
- sqlserver/sqlserver_demo.ipynb
- oracle/oracle_demo.ipynb
- postgres/postgres_demo.ipynb
- sqlite/sqlite_demo.ipynb

## Install

```bash
pip install "lakelogic[azuresql]"
pip install "lakelogic[sqlserver]"
pip install "lakelogic[oracle]"
pip install "lakelogic[postgresql]"
```
